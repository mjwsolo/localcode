# Commands

LocalCode is designed to work without commands. Just describe what you want and the model does it. There's only one command you need to know:

## `/switch`

Toggle between fast and reasoning mode.

```
/switch  →  Switched to reasoning mode (26 tok/s, thinking on)
/switch  →  Switched to fast mode (27 tok/s, thinking off)
```

**Fast mode** — quicker answers for routine work. No thinking overhead.

**Reasoning mode** — the model thinks step-by-step before responding. Use this for complex multi-step problems.

That's it. Everything else — reading files, writing code, running commands, searching — the model handles automatically.
