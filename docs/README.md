# LocalCode Documentation

## What is LocalCode?

LocalCode is a local-first AI coding assistant that runs entirely on your machine. No cloud, no API keys, no data leaving your laptop. It runs Gemma 4 26B — a 25 billion parameter model — on a 16GB MacBook at 26 tok/s with 32K context.
