# 3 Tips for Learning Python

## 1. Code Every Day

Even 20 minutes of practice beats one long weekly session. Build small scripts,
complete exercises on platforms like LeetCode or Codewars, and gradually increase
complexity as your confidence grows.

## 2. Read Other People's Code

Study open-source projects on GitHub, follow Python blogs, and examine popular
libraries. Reading clean, well-written code exposes you to idioms and patterns
you won't discover by writing in isolation.

## 3. Build Real Projects

Apply what you learn by creating something tangible — a web scraper, a CLI tool,
a data visualisation, or a simple game. Projects cement knowledge far more
effectively than tutorials alone.
