Build a small inventory-management package across multiple files. `models.py`: an `Item` class constructed as `Item(sku, name, qty, price)` exposing those four attributes. `store.py`: imports `Item` from `models` and defines `InventoryStore` with methods `add(item)`, `get(sku)` (returns the Item), `restock(sku, n)` (increase qty by n), `sell(sku, n)` (decrease qty by n, raising `ValueError` if n exceeds the current qty), `low_stock(threshold)` (return the list of skus whose qty is strictly below threshold, in insertion order), and `total_value()` (sum of qty*price across all items). `report.py`: imports `InventoryStore` and defines `summary(store)` returning a dict `{"items": <count>, "total_value": <number>, "low_stock": <list of skus below 5>}`. Finally add `test_inventory.py` with pytest tests covering the above. Build it incrementally and keep it runnable.
