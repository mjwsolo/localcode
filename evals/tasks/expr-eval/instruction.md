Create `calc.py` with a function `evaluate(expr)` that parses and evaluates an arithmetic expression string. Support `+`, `-`, `*`, `/` with standard operator precedence (`*` and `/` bind tighter than `+` and `-`), parentheses for grouping, and unary minus. Subtraction and division are left-associative. Division is real (float) division. Whitespace in the input is ignored. On malformed input (e.g. `"2+"`, `"(1"`, empty), raise `ValueError`. Do NOT use Python's built-in `eval`/`exec`.
