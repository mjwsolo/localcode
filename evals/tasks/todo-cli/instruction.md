Create `todo.py`, a command-line todo app using `argparse` that persists tasks to a file `todos.json` in the current directory. Support four subcommands: `add <text>` appends a task; `list` prints every task on its own line as `<index>: [ ] <text>` (or `[x]` when done), zero-indexed in insertion order; `done <index>` marks a task done; `rm <index>` removes a task. State must persist across separate invocations (read/write `todos.json`). `list` with no tasks prints nothing and exits 0. An out-of-range index for `done` or `rm` must exit with a non-zero status.
